# AI-Powered Reserve Pilot Training Platform

AeroSim is a comprehensive flight simulation framework. Pegasus Simulator is a framework. B-ACE Beyond Visual Range Air Combat Environment. AMASE is a simulation toolset. AirspaceConverter is a multi-platform and open source tool. The OpenHornet Project is a F/A-18C OFP 13C Lot 20 1:1 Replica Simulator. OpenAvionics is a hardware/software project to design low cost instrumentation. JSF AV C++ standard. PSim-RCAM - Simulation Research Civil Aircraft Model. Supercell is a Rust-based simulation controller. Worldview is a CesiumJS viewer for DIS-backed simulations. OpenLVC Portico is an open source, cross-platform, fully supported HLA RTI. Extensible Modeling and Simulation Framework (XMSF). QF-4E Drone AI system simulating a CCA OODA cycle. Open Mission Systems (OMS). Modular Open Systems Approach (MOSA). FlightGear has been equipped with a number of different aircraft carriers that allow pilots to simulate the entire range of carrier operations. Flight dynamics library for Modelica. AirSim is an advanced simulation platform. AutonomySim is a high-fidelity, photorealistic simulator. BlueSky is a software tool for fast, real-time simulation of air traffic. Albatross Display is an open source ATC environment. OpenTMS ATMS is a data-driven decision support system. OpenEaagles is a "multi-platform simulation platform designed to help engineers and software developers rapidly prototype and build robust, scalable, virtual and constructive, and stand-alone and distributed simulation applications". OpenFighter open-source initiative to collaboratively design a complete fighter aircraft platform. A high-fidelity 6dof dynamic model of fighter F16 based on NASA aerodynamics data

The directory structure includes a specific folder for each phase of development and engineering programs:

- __MBSE__: The root folder Arcadia (ARChitecture Analysis and Design Integrated Approach) is a method of tools dedicated to systems engineering and architecture, supported by the Capella modeling tool.    
  - __CAD__: For computer-aided design.
  - __CAM__: Dedicated to the part manufacturing and assembly process.
  - __CAS__: For simulation of end-to-end functionality and performance analysis.
